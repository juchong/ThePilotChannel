Airports

One local traffic view per airport, in this order. Use the identifier its weather reports carry: KSEA, or for a US field without one, K and its FAA identifier (KS50).

Regions and radar

A wider view for the weather: wind barbs for every reporting airport inside it, over the radar loop.

Satellite

The NOAA GOES loop. The sector code is the short code in the address of your region's page on the NOAA STAR image viewer (pnw, psw, ne, …).

Cameras

Live video tiles in the rotation. A stream's address is stored on the Pi; after storing, only its host is shown.

Streams

Changes here apply at once and never reload the TV. Paste the RTSPS link from UniFi Protect (the camera's settings, Advanced, RTSP); its ?enableSrtp ending is removed.

Layout on the TV

Six columns wide. A tile two columns wide shows 16:9 video at full size; four columns suits a panoramic camera.

NOTAMs

One view per location: the NOTAMs in effect and those starting soon, grouped by type, with times in the display's time zone. Each card also shows the NOTAM as issued, with its UTC times.

In the rotation

FAA NOTAM service

The FAA issues a key and a secret for each environment (email NOTAMS@faa.gov for access). Each pair is stored on the Pi and sent only to its own environment.

Locations

An airport, NAVAID or center by its identifier (S50 or KS50, KSEA, ZSE). The display makes one data pull every three minutes, the most production allows, so a new location and Refresh now wait for the next turn.

Requests to the FAA, last 24 hours

Download the record

The totals are those of the environment in use. The record holds every request to each environment, with its time, kind, status and the id the FAA gave it.

Account

API keys

For Home Assistant and scripts. A key is sent as the header Authorization: Bearer followed by the key. It can never read or change what is on this page.

Stored secrets

Kept in data/secrets.json on the Pi. A stored value is never sent back to a browser.

Display API

How a program on your network reads what the TV shows, changes the view and blacks out the picture, filled in with this display's address and views. Copy it into an agent or a project that will make the calls. It never holds a key: create one under Access.
